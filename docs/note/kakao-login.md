# Local Kakao Login Test

## 목적

로컬 환경에서 카카오 로그인 리다이렉트 흐름을 확인하기 위해서 임시 정적 서버를 실행하여 동작하도록 한다.

## 배경

카카오 로그인은 클라이언트가 인증을 완료하면 등록된 Redirect URI 로 **인가 코드**를 반환한다.
이후 인가 코드를 바탕으로 카카오 서버에서 인증 토큰 요청을 통해 로그인을 하게 된다.

## 설정 내용

- 카카오 데빌로퍼스에 Gongu 앱 추가
- 대시보드 > 설정 > 카카오 로그인 : 설정하기
- 앱 > 플랫폼 키 > REST API 키 수 > 로그인 리다이렉트 localhost:9000 으로 설정 
- 클라이언트 시크릿 비활성화

## 실행 방법 
```bash
cd src/main/resource

python3 -m http.server 9000
```
